# vlmcsd Per-Request ePID Scope Backport

Base packages feed: `03d8b9d71b5e27972e4111ebe39898d093544c92`, package
`net/vlmcsd`, release8. Source: `Wind4/vlmcsd` commit
`e599080486478e219cd065e141d6de050a450c27`. The original package has no patches.
The complete base recipe SHA256 is
`445faf46fe37f35c3826fdd350f33ace58bdc55531e23b847f9dd4a25849f1a8`.

`RandomizationLevel == 2` assigns `pid` to a block-local `ePid` and converts
it after that block ends. Move only the declaration to the containing function
scope, still under `NO_RANDOM_EPID`'s inverse guard. It remains per-call stack
storage, not shared/static storage. Generation, conversion, configured/default
PID choice, HWID copying and logging are unchanged.

The source is CRLF. Patch metadata/hunk headers are LF; hunk payloads retain CRLF
to match the actual pinned bytes. Do not normalize this patch. The helper pins
its full hash and the test applies it with a real patch tool to the exact source,
checking declared coordinates, every source byte and preservation of CRLF.

Run `python3 AX6-IPQ/scripts/apply-vlmcsd-scope-backport.py apply feeds/packages`
from the build repository. Only the recipe's release8-to9 line and this single
package patch are installed. `check` validates the resulting package bytes;
`prepared SOURCE` validates all104 files from the exact OpenWrt mirror archive,
not only `src/kms.c`. The mirror SHA is the unchanged package `PKG_MIRROR_HASH`.
Its102 code/data files equal the pinned Git and submodule sources; rawgit removes
root `.gitmodules` and leaves two fixed submodule `.git` text pointers. They are
inspected as inert data, never followed or used as Git directories. Empty `.prepared_*` markers and decimal
`version.date` generated by the selected OpenWrt prepare recipe are explicitly
reported as metadata, not treated as upstream source. Other files fail closed.
No network/build/source execution occurs in the helper.

Unknown full recipe bytes, changed source pin, extra/missing/corrupt patches,
symlinks, wrong file modes, cooperative lock contention and mixed partial states
are rejected. Staging is followed by input rechecks and two file renames, not an
atomic multi-file transaction. A second-rename failure leaves a rejected partial
state rather than silently repairing it. This lock does not serialize unrelated
writers or eliminate filesystem TOCTOU/power-loss risks. No whole-feed HEAD or
artifact provenance claim follows from matching this one package's bytes.

`tests/test-vlmcsd-scope-backport.py` consumes the exact local packages Git object
and pinned source archive, without running source build scripts. It extracts
complete real selection, generation and UTF8/UCS2 conversion functions and uses
real upstream types/headers. Only libc random/time inputs are deterministic host
models. Native tests cover random levels0/1/2, configured/default/generated PIDs,
HWID and log behavior, disabled-random profiles, exact output and semantic
mutations. Original-scope sanitizer detection is a separate historical bug
witness, never a semantic-mutant PASS. No warning is disabled to hide the bug.
